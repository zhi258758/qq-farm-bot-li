- [x] 1. 用户、卡密、运营配置存储
  - 新增 `user-store`、`cardkey-store`、`auth-config-store`
  - 游戏账号增加 `ownerUserId`，存量账号归属管理员
  - 普通用户密码仅要求非空；卡密生成数量为正整数即可
- [x] 2. 会话鉴权与租户过滤
  - 令牌改为带身份的会话
  - HTTP 与 Socket 按角色过滤游戏账号
  - 注册、登录、资料、改密接口支持普通用户
- [x] 3. 卡密兑换与管理员后台 API
  - 时间卡密累加到期时间，额度卡密增加槽位
  - 管理员开关、用户列表、生成/查询/作废卡密
  - 会员过期与槽位不足时拒绝新增账号和启动挂机
- [x] 4. 运行时会员守卫
  - 过期或禁用用户停止 worker
  - 管理员不受会员和槽位限制
- [x] 5. 前端登录、会员卡密与管理页
  - 登录页按开关显示注册
  - 用户设置页兑换卡密并查看权益
  - 管理员菜单进入用户与卡密后台
- [x] 6. 检查点 - 确保核心用例可运行
  - 确保所有测试通过,如有疑问请询问用户
